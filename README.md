##  Program Details

The MotorPH Payroll System is a Java console application that automates payroll processing for MotorPH employees.

**How it works:**
1. The user logs in as either a **Payroll Staff** or an **Employee**
2. **Employees** can look up their basic personal information using their employee number
3. **Payroll Staff** can process payroll for one specific employee or all employees
4. The system reads employee details and attendance records from CSV files, then computes each employee's salary from **June to December 2024** on a **semi-monthly cutoff** basis (1–15 and 16–end of month)
5. Government deductions — **SSS, PhilHealth, Pag-IBIG, and Withholding Tax** — are automatically calculated based on the employee's monthly gross salary and subtracted to produce the **net salary**
